Organizador Automatico de Arquivos

Este programa organiza os arquivos de uma pasta de acordo com seu tipo
Se uma pasta esta cheia de exe, txt, docs, pdf, etc espalhados e desorganizados, o codigo irá criar pastas com seus tipos de organiza-las automaticamente

Pré-requisitos
 Python (versão 3.8 ou superior recomendada)
  Para verificar se você já tem o Python instalado, execute o seguinte comando no seu terminal: python --version
  (Caso não tenha, faça o download e a instalação em python.org.)
